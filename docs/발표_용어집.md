# 발표 용어집 (발표 스크립트와 별도, 이해용)

발표할 때는 스크립트를 그대로 읽고, 이 문서는 뜻을 이해하는 데만 쓴다.

## 장마다 나오는 말

| 말 | 읽는 법 | 뜻 (쉽게) |
|---|---|---|
| 장애 | 장애 | 서비스가 멈추거나 느려지는 사고 |
| AI 비서 / 에이전트 (Agent) | 에이전트 | 질문을 받아 스스로 조회·판단·답까지 하는 AI 프로그램 |
| 당직자 | 당직자 | 밤에 장애에 대응하는 담당 개발자 |
| DB 프라이머리 (DB Primary) | 디비 프라이머리 | 데이터를 저장하는 주(메인) 데이터베이스 서버 |
| 매뉴얼 / 런북 (Runbook) | 런북 | 장애 유형별 대응 절차서. 이 프로젝트엔 6개 |
| 모니터링 경고 문구 | 모니터링 | 서버 상황판이 띄우는 알림 문장 (예: 지연 2.4초 초과) |
| 누락 | 누락 | 써야 할 맞는 매뉴얼을 빠뜨림 |
| 혼입 | 혼입 | 상관없는 매뉴얼이 섞여 들어옴 |
| RAG | 래그 | 질문 뜻에 맞는 매뉴얼을 찾아서 AI에게 같이 주는 방식 (맞는 페이지 펴 주기) |
| Judge | 저지 | 답을 한 번 더 채점하는 AI 채점관 (4가지 기준으로 합격/불합격) |
| 캐스케이드 (Cascade) | 캐스케이드 | 싼 작은 모델이 먼저 쓰고, 불합격일 때만 비싼 큰 모델이 다시 씀 (신입 먼저, 막히면 선배) |
| v2 보완 | 브이투 보완 | 두 번째 개선판. 맞는 매뉴얼이 없으면 억지로 고르지 않고 "없다"고 말하게 함 |
| 비동기 (Async) | 비동기 / 에이싱크 | 질문을 한 줄로 세우지 않고 동시에 처리 |
| 고장 허용 | 고장 허용 | 조회 하나가 실패해도 나머지 정보로 끝까지 답함 |
| 스위치 | 스위치 | 개선 기능을 설정으로 켜고 끌 수 있게 만든 것 |
| Ablation | 어블레이션 | 스위치를 하나씩 켜고 끄며 어떤 기능이 진짜 효과였는지 가리는 실험 |
| 7가지 버전 | 일곱 가지 버전 | 스위치 조합으로 만든 7개 구성 (원본, +RAG, +Judge 등) |
| holdout | 홀드아웃 | 개발 중 한 번도 안 보고 마지막 평가에만 쓴 시험 문제 36개 |
| 연습 문제 (dev) | 데브 | 기준값을 정할 때만 쓴 문제 24개 |
| 짝지어 비교 | 짝지어 비교 | 같은 문제끼리 "켰을 때 - 껐을 때"를 비교 |
| 신뢰구간 | 신뢰구간 | 진짜 효과가 있을 법한 범위. 이 범위에 0이 없으면 우연이 아닌 효과 |
| %p (퍼센트포인트) | 퍼센트 포인트 | 비율끼리의 차이. 56%에서 9%면 47%p 줄어든 것 (%와 다름) |
| 지연 | 지연 / 레이턴시 | 답이 나오기까지 걸리는 시간 |
| 질의 | 질의 | 질문 1건 |
| 같은 부하로 재측정 | 같은 부하 | 모든 버전을 같은 조건(동시에 같은 양)으로 다시 재서 공정하게 비교 |
| 5회 반복 | 다섯 번 반복 | 같은 시험을 5번 돌려 결과가 우연이 아닌지 확인 |
| 커넥션 풀 (Connection Pool) | 커넥션 풀 | DB에 미리 열어 둔 연결 묶음. 응답 지연 때 늘리는 조치 |
| failover | 페일오버 | 메인 DB가 죽으면 예비 DB로 바꿔 타는 조치 |
| Recall@1 | 리콜 앳 원 | 1순위로 고른 매뉴얼이 정답인 비율 |
| 합성 평가셋 | 합성 평가셋 | 실제 기록이 아니라 직접 만든 시험 문제 |
| 사람 채점 | 사람 채점 | 사람이 답을 직접 채점한 것 (아직 안 함) |
| 커밋 (Commit) | 커밋 | 코드 저장 기록. 시각이 남아서 "언제 고정했는지" 증명 가능 |

## 로컬 실행 (8장)

| 말 | 읽는 법 | 뜻 (쉽게) |
|---|---|---|
| 로컬 | 로컬 | 인터넷 서비스가 아니라 내 컴퓨터 안에서 실행 |
| Ollama | 올라마 | 내 컴퓨터에서 AI 모델을 돌리게 해 주는 프로그램 |
| qwen3 8B | 큐웬 쓰리 에잇비 | 알리바바가 만든 공개 AI 모델. 8B는 크기(파라미터 80억 개) |
| OpenAI | 오픈에이아이 | GPT를 만든 회사. 실험은 이 회사 API로 측정 |
| API | 에이피아이 | 다른 회사 AI를 인터넷으로 빌려 쓰는 창구 (쓸 때마다 요금) |
| 모델을 바꿔 끼우는 구조 | 모델 교체 | 코드는 그대로 두고 쓰는 AI만 바꿀 수 있게 만든 설계 |
| 주소만 바꿔서 | 주소 교체 | AI를 부르는 인터넷 주소를 내 컴퓨터 주소로 바꿈 |
| 임베딩 (Embedding) | 임베딩 | 문장을 숫자 묶음으로 바꿔 "얼마나 비슷한지" 계산하게 하는 것 |
| 기준값 (threshold) | 기준값 / 스레숄드 | 이 점수 이상 비슷해야 매뉴얼로 고른다는 커트라인 |
| 망분리 | 망분리 | 보안 때문에 회사 내부망을 인터넷과 끊어 둔 환경 (금융·공공) |

## 예상 질문에 나오는 말

| 말 | 읽는 법 | 뜻 (쉽게) |
|---|---|---|
| 효과가 확인되지 않았다 | | "효과 없다"가 아니라 "있다고 말할 근거가 부족하다" |
| 코드로 사실 확인 | | 숫자가 근거에 있는지 AI 대신 프로그램이 직접 대조 |
| 캐시 (Cache) | 캐시 | 같은 질문이 오면 저장해 둔 답을 재사용해 비용 절약 |
